## 一、谷圈（二次元周边）品类：用户心智与黑话

**品类构成**：谷子 = Goods / グッズ 的谐音。主要形态 **吧唧**（徽章，最热门，多按系列盲盒盲袋贩售）、**亚克力立牌**、**色纸**、**流麻**、**镭射票**、贴纸、钥匙扣。
来源：https://zhuanlan.zhihu.com/p/678266499 · https://www.bilibili.com/read/cv20592349

**人群**：核心受众年轻，**近四成 18-23 岁**，女性用户占比高。定价按质量/发行数/角色 IP 形成圈内独有体系。
来源：https://news.qq.com/rain/a/20241024A06ONX00 · https://m.21jingji.com/article/20241129/herald/04161b7231e60a20aa1a7fe605a1854e.html

**★★ 关键交易黑话（直接关系到本项目的产品形态）**：

| 黑话 | 含义 | 对本项目的意义 |
|---|---|---|
| **现货** | 卖家手里已有、随时可发 | 本项目商品表**没有这个字段**，客人无法区分 |
| **空气谷** | 已买但还没到手的货 | 本项目卖的**全是空气谷**，但产品里一个字没提这个概念 |
| **补款** | **定金预售**模式：先付定金，货到卖家仓库后通知补尾款再发货 | ★ 这是谷圈**标准交易模式**，而本项目是**全款预付**。商业模式层面的差异 |
| **代拍** | 代购在日本店里拍照，群友圈想要的，委托代购下单 | ★ 正是甲方说的「代切/煤炉」二期形态 |
| **吃谷** | 购买谷子 | 文案可用 |

来源：https://www.qingdaonews.com/wap/2025-04/18/content_23655667.htm · https://zhuanlan.zhihu.com/p/678266499 · https://www.zhihu.com/question/292646747

**判断**：「现货 vs 空气谷」是谷圈用户下单前**最在意的区分**，圈内有专门的词。本项目商品完全不表达这个，客人只能看一个可为空的自由文本「预计到货」。

## 二、日本代购 / 海淘：成熟做法与客人的担忧

**客人最担心的**（按提及频次）：正品、汇率、关税、丢件、退款、到货时间。跨境代购因**地理隔离 + 信息不对称 + 客单价高**，消费者最看重「正品保障」。
来源：https://pdf.dfcfw.com/pdf/H3_AP202106151498097680_1.pdf（中国跨境海淘白皮书）

**成熟平台的信任建设手段**：
- 全流程透明：专柜直采 → 权威质检 → 合规跨境物流 → 分层客服
- **每批货保留完整采购记录、来源链路可溯**
- 真实用户评价
- 多数售后 24h 内解决，反馈通道常开
来源：https://digi.china.com/articles/20260622/202606221899056.html

**代购系统的常见功能**：24h 接单、实时库存同步以减少缺货纠纷、订单状态跟踪（已确认/在途/无效）、多支付方式（含**客户预存余额**）。
来源：https://blog.csdn.net/johnny925870075/article/details/89015754 · https://blog.csdn.net/API_Json/article/details/130363246

**缺货处理**：收货后发现问题可协商，通常需**照片或试用视频**举证，退换有时限，各家规则不同。
来源：https://www.jchere.com/daigou/help.htm

## 三、微信小程序：分享与订阅消息的能力边界

**★ 诱导分享是明令禁止的**。违规形态包括：
1. 强制分享才能用功能 / 看内容
2. 分享后立即获益（显性或隐性）
3. 分享得红包封面
4. 分享到群/好友只需极少互动即可获益
5. **用财物激励分享到朋友圈**
6. 隐性诱导（如小红点提示）
7. 过度营销式分享

案例：做任务给金币（分享给好友得币）属违规；「晒朋友圈得好处」属违规。
来源：https://developers.weixin.qq.com/community/develop/doc/000cac357f0bd865c289b69365b400 · https://developers.weixin.qq.com/community/develop/doc/000086404ac470274a1acc2a851809

**→ 结论**：**普通分享（`onShareAppMessage` / `onShareTimeline`）本身完全合规**，红线在「用利益换分享」。本项目现在一处分享都没实现，属于把合规的获客通道也一起关了。

**订阅消息机制**：
- 用户必须主动订阅才会下发
- **一次订阅 = 一条消息**；拒绝且勾「保持选择」后不再弹窗
- **可重复授权，每次授权单独存一条记录**（即额度可累积）
- 电商场景（支付提醒、物流消息）订阅率较高
来源：https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/order-shipping/order-shipping.html · https://help.fxiaoke.com/b2b6/de6c/8874/43d7 · https://cloud.tencent.com/document/product/1301/103770

## 四、限时场次 / 稀缺感的机制设计

**秒杀三要素**：**限时 + 限量 + 限价**，缺一个活动就没意义。
来源：https://developers.weixin.qq.com/community/develop/article/doc/000c4615c0c128b7516c765ba51013

**倒计时**：放在商品详情的购买按钮区，显示「本场优惠还剩 XX 小时 XX 分」。
来源：https://blog.csdn.net/weixin_46447290/article/details/128159791

**社会证明**：展示「XX 人已购买」或「库存告急」，会让用户产生「这么多人买了应该不会错」的心理，加速决策。
来源：https://developers.weixin.qq.com/community/develop/article/doc/000a4eebe146585e6a6c1fb8256413 · https://www.eshutong.com/archives/40705.html

**团购接龙**：团长在社群发商品信息，居民以接龙表达购买意愿。
来源：https://blog.csdn.net/weixin_40060468/article/details/132779462

**⚠️ 注意适配**：本项目**不是社交拼团**（无成团人数、无邀请、无阶梯价），「差 X 人成团」不适用。
但「限时」本项目有（场有起止时间）、「限量」**本项目完全没有**（一期无库存概念）、「社会证明」也没有。
三要素里只做到了一个，而且倒计时只在场详情页有、商品详情页看不到。
