## 根因

**①** `gz_bean_seat_type_config.enabled` 是唯一开关且**四处耦合**（mp type-slots / 看板 / 座位批量生成 / walk-in）。停用桌型 = 小程序不显示 **且** 看板上该桌型座位全消失。系统缺少「只对小程序隐藏、看板照常」的能力。

**②** 回收占用单位是 admin 配的**命名时段档**（上午 10-13 / 下午 15-18 / 晚上 19-22），每档恒 1 单，最高点数档靠 `occupy_next_slot` 额外占**下一个档**。日容量 = 3 单。

点数档 seed 注释本来就写着「每 50 点约 1 小时」，`duration_minutes` = 60/120/180/240/300 **完全吻合甲方口径** —— 改造不需要动点数档数据，只需把这一列从「仅展示的预计时长」升格为「驱动占几个小时格」。

## 预期结果

- 周末临时加桌能在看板计时，不用写纸条
