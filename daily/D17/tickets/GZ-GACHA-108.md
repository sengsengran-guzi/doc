## What

把扭蛋开盒页（draw.vue + BizGachaDraw.vue）重做成**竞品式按钮触发的暗场开盒**（**去掉摇一摇**）：详情页点抽 → 支付 → 自动播放「暗场发光神秘胶囊(?) + 漂浮星点 → 裂开 + 稀有度光晕 + 粒子」→ **恭喜获得**结果（实物大图 + 名称 + 稀有度 + 参考价）→ **领取**(→背包)/再抽一次。结果与稀有度全由后端 + admin 配置驱动；暗场仅动画那一刻，揭晓回清爽亮底。

## AC（验收标准）

- [ ] **AC1 暗场开盒动画**（去摇一摇）：drawn 后自动播放 opening（暗场发光神秘胶囊 ? + 环境氛围光 + 漂浮星点）→ crack（anticipation 收缩→pop→上下两半分离 + 中心稀有度光晕 + 粒子爆发）→ reveal。无用户摇动/手势。
- [ ] **AC2 恭喜获得 + 领取背包**：reveal 弹「恭喜获得」+ 实物大图 + 名称 + 稀有度角标 + 参考价；主 CTA「领取」→ 背包（GACHA-106 我开过的/待发货列表），次 CTA「再抽一次」→ 回详情。
- [ ] **AC3 揭晓动画质量**（逐条可测）：
  - (a) 实物 spring 弹入（`cubic-bezier(.34,1.56,.64,1)`）+ 稀有度光晕 `--c-r-*`（非 burst）。
  - (b) staggered：实物 → 恭喜 → 名称 → 稀有度 → 参考价 → CTA 依次错峰入场（`animation-delay` 链）。
  - (c) 稀有度差异化：SSR/SR 加一层缓转柔光底 + 更长光晕呼吸。
  - (d) 全 transform/opacity 关键帧，不在动画循环内 `setData`。
- [ ] **AC4 震动同步**：crack + reveal 关键帧 `uni.vibrateShort/Long`，按稀有度分档（N/R 单短震；SSR 长震+三连）；try-catch 兜底、尊重静音。
- [ ] **AC5 低端机降级**：`isLowEndDevice` 命中 → 跳过 opening + crack，直接 reveal 渐入。
- [ ] **AC6 后台可配置驱动**：实物图（image_id→url）/稀有度/名称/参考价 全读后端 VO，无硬编码；缺图走清爽柔和色块占位。
- [ ] **AC7 合规护栏**：① 文案「开盒/获得/恭喜获得/领取」，禁抽奖系词；② 揭晓忠实后端真实结果，无 near-miss；③ 概率公示（详情页）不受影响；④ **不照抄竞品 C2C 集市/假抽/支付规避**（竞品「请勿用微信支付」= 抽赏被微信限，我们走微信支付须守合规）。
- [ ] **AC8(a) AI 模拟器可达**：kevin-qa 用 `test/e2e` reLaunch draw + wxMOCK 短路 → 断言 opening/reveal 渲染 + 恭喜获得 + 领取 CTA。新增 gacha-draw flow。
- [ ] **AC8(b) Tier 2 真机人验**（碰真机原生：真实支付 + 震动）：详情页投币 → 支付 → 真机看开盒动画/震动/观感拍板。
