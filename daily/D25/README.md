## 现状

全项目只有资讯详情页（GZ-NEWS-002）有分享，其余页面**右上「…」的「转发」是灰的、点不动**。

## ⚠️ 撞到的 uni-app 硬约束（重要，后续加分享页必读）

**分享钩子不能抽进 composable**：uni-app 靠**对页面文件自身源码做字面量正则匹配**决定是否暴露分享能力，
调用藏在别的模块里 → `__runtimeHooks = 0` → 微信不知道这页能转发，**且不报任何错**。

第一版正是这么写的，单测/TS/lint 全绿，**真模拟器一跑全 false**。已改成「composable 出内容、页面自己注册钩子」。

衍生：「我的」页要「有好友分享但无朋友圈」，表现为**连 `onShareTimeline` 的 import 都不能有**。
