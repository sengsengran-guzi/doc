## GZ-BEAN-015 拼豆付费页（拼豆 tab，N=1 可达）

**入口**：底部「拼豆」tab → 拼豆付费页（已上线 3-tab，直达）。

| # | 步骤 | 预期 | ✅/❌ |
|---|---|---|---|
| 1 | 进拼豆 tab | 报头「拼豆预约」+ 成都门店（单店无切换） | ⬜ |
| 2 | ① 选日期（默认今天，7 天） | 日期切换 → 自动刷新座位类型余量 | ⬜ |
| 3 | ② 选座位类型 | 显单人/双人/四人桌 + 单价（¥X/位）；全满类型灰显不可选 | ⬜ |
| 4 | ③ 选时段 | 选定类型后显各时段「还剩 N 个」/「已满」灰显；单选（非累加） | ⬜ |
| 5 | ④ 选券 | 优惠券入口行 → 点开底部弹层选券（仅适用拼豆未过期）；金额区显单价−券=实付 | ⬜ |
| 6 | ⑤ 采手机号 | 未绑 → getPhoneNumber 原生授权弹窗 → 绑定后显脱敏号 | ⬜ |
| 7 | ⑥ 填微信号 | 未填 → input 填微信号 → 保存（updateProfile）→ 显已填 | ⬜ |
| 8 | 提交（手机+微信号齐才可点） | CTA「支付预约」可点 → wx.requestPayment 拉起（mock 模式） | ⬜ |
| 9 | mock 支付成功 | 跳预约详情 → 看门店/类型/时段/实付/**核销码二维码** | ⬜ |
| 10 | 约满拒单 | 选已满时段 → 灰显不可选；或提交瞬间约满 → toast「已约满，请重选」 | ⬜ |
| 11 | 再约一笔 | 详情/列表可再发起一笔（多类型/多时段 = 多次预约） | ⬜ |
| 12 | C 设计系统遵循 | 粗墨边 / 朱红选中 / 硬投影 / 报头风 / 不混 emoji | ⬜ |

**微信原生能力**（真机必验）：getPhoneNumber 授权 + wx.requestPayment 拉起（mock 商户）。
