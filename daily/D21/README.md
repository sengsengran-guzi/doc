## 范围与顺序

甲方要求「后台可以自己关闭时间」+「类似拼豆的排位，店员直观看到怎么排，有时候要给老师调整（周一下午改周二上午）」。ADR-0021 把它收敛成三件事：**手动占用时段**（代客预约与临时关闭是同一机制）、**预约改期**（原地 UPDATE）、**回收看板周视图**（承载面）。

| Ticket | 层 | 内容 | 依赖 |
|---|---|---|---|
| GZ-RECYCLE-010 | 后端 | 迁移（appointment 加 `source` / 审计三列 + 放宽三列 NULL）+ `manualHold` / `releaseHold` / `reschedule` / `weekBoard` 四端点 + 容量校验抽公共方法给 submit/hold/reschedule 三处共用 + 错误码 4128/4129 + menu 13015/13016 | — |
| GZ-RECYCLE-011 | admin | `gz-recycle/appointment/index.vue` 顶部看板由「今日分组」改**周矩阵**（7 天 × 该店 enabled 时段，格四态）+ 手动占用弹窗（多选格 + 备注）+ 改期弹窗；下方回收记录列表不动 | 010 |

mp 端**零改动**（`slot-availability` 自动继承新占用态；mp 店员当日列表由 010 在后端排除手动记录）。看板只做 plus-ui 电脑后台，不做 mp 店员端镜像。
